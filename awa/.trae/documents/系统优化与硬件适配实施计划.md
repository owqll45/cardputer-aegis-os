# 安卓化系统架构与智能进程管理方案 (V2)

## 1. 智能进程分级管理 (Smart Process Killer)
- **区分系统/用户**：为所有应用添加属性，区分“系统核心”与“用户应用”。
- **定向清理**：内存不足时，仅提示并清理“用户应用”的后台进程。
- **系统保护**：严禁自动杀除系统进程，确保系统基础功能（如键盘、UI调度）永不崩溃。

## 2. 系统异常诊断与报错 (System Memory Audit)
- **内存泄漏检测**：若系统进程占用异常，弹出红色报错窗并输出详细 LOG。
- **日志 Dump**：自动将当前的内存分布快照（Memory Map）写入 SD 卡 `/sd/logs/` 目录下，方便定位系统级 Bug。

## 3. 硬件级内存扩容 (8MB PSRAM)
- **开启 SPIRAM**：修改 `sdkconfig` 启用 8MB PSRAM。
- **内存隔离**：系统内核驻留内部 SRAM，用户应用驻留外部 PSRAM。

## 4. 安卓化存储与 UI 规范
- **存储规范**：统一 `/sd/system/` 与 `/sd/apps/` 目录结构。
- **交互规范**：全系统确认操作统一 3 秒长按逻辑，进度条视觉反馈与报错系统对齐。

## 5. 心率全数据监控
- **原始字节流**：在 monitor 和 SD 卡日志中同步输出 BLE 原始 HEX 数据。

## 6. 编译刷入 (Flash & Monitor)
- 执行 `idf.py build flash monitor`。
