# “哨兵-超脑内核” (Sentinel Brain-Core) v3.4 进化补完计划

## 1. 核心修复：系统 UI 字体沙盒 (Font Sandbox)
- **上下文保护**: 在 `crash_handler` 中实现 `UIContextGuard`。
  - 绘制弹窗前保存 `font`, `datum`, `textColor`, `cursor` 等全局状态。
  - 强制设置系统标准字体（`efontCN_12`）进行绘制。
  - 绘制结束后还原所有状态，确保弹窗不随 App 变化。
- **全屏渲染**: 优化弹窗为全屏/半透明蒙层模式，解决“窗口太小显示不全”的问题。

## 2. UI 进化：传感器美学迁移

- **全局拦截**: 在 `Hal::update` 中实现按键过滤，确保系统功能不干扰游戏方向键。
