# 🛠️ 固件与 App 双端终极强化计划 (Priority Overlay Edition)

收到！**弹窗优先级 (Overlay Priority)** 是用户体验的核心。不能让普通的“操作确认”挡住了关键的“爆炸警告”。

以下是包含**严格优先级系统**的最终方案：

## 1. 🚨 全局弹窗优先级系统 (Overlay Priority System)
App 将引入一个**严格的弹窗调度器**，确保重要信息永远最先显示：

*   **Priority 1 (最高级 - 无法关闭)**：💀 **BOOM (引爆)**
    *   全屏深红闪烁，覆盖一切，必须物理重置设备才能消失。
*   **Priority 2 (极高级 - 强制阻断)**：🔒 **DEVICE LOCKED (锁定)**
    *   全屏红色，必须输入密码/指纹解锁才能操作。
*   **Priority 3 (高级 - 决策层)**：⚡ **ADMIN CONFIRM (上帝之手)**
    *   当您点击“加速/惩罚”时弹出的验证窗。
    *   **关键逻辑**：如果此时设备突然爆炸 (Level 1)，这个弹窗会被**立即顶掉**，优先显示 BOOM。
*   **Priority 4 (中级 - 警告)**：⚠️ **SECURITY ALERT (移动/防拆)**
    *   橙色警告，可手动忽略。
*   **Priority 5 (低级 - 通知)**：ℹ️ **SYSTEM INFO (操作反馈)**
    *   顶部通知条，3秒自动消失。

## 2. 🚀 “上帝之手” 确认流程
*   点击 **[2X SPEED]** -> 弹出 **Priority 3** 确认窗 -> 验证指纹 -> 发送指令。
*   如果在此期间设备被引爆 -> **Priority 1** 弹窗直接覆盖确认窗。

## 3. ⏳ 倒计时防丢失
*   **Service 托管**：Service 负责维护倒计时状态，Activity 只是显示器。切屏回来直接从 Service 拿数据，秒级恢复。

## 4. 🛡️ ADV 固件端 (ESP32)
*   **终端分栏**：左输入，右指令表。
*   **变速指令**：支持 `SPEED:DOUBLE`。
*   **强制清屏**：修复残留。

## 5. 📱 App 功能回填
*   **🔴 PANIC / 📏 距离 / 📳 震动 / 🛠️ 工具箱** 全部加回。
